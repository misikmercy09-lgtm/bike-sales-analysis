# Bike Sales Analysis

## Project Overview

This project explores a bike sales dataset to understand what factors influence customer purchasing decisions. The goal is to extract insights that could help a business improve targeting and sales strategy.

## Problem Statement

Bike retailers need to understand which customer segments are more likely to purchase bikes. This analysis focuses on identifying patterns across demographics, income levels, and lifestyle factors.

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib 
* Jupyter Notebook

## Dataset Description

The dataset includes customer attributes such as:

* Age
* Income
* Gender
* Marital Status
* Occupation
* Region
* Commute Distance
* Bike Purchase (Yes/No)

## Data Cleaning

* Checked for missing values
* Standardized column formats
* Converted categorical variables where necessary

## Exploratory Data Analysis

Key areas explored:

* Income vs Purchase behavior
* Age distribution of buyers
* Gender-based trends
* Commute distance impact

## Key Insights

* Customers with higher income showed a higher likelihood of purchasing bikes
* Middle-aged individuals were the most active buyers
* Shorter commute distances correlated with higher purchase rates
* Certain regions showed stronger demand patterns

## Business Recommendations

* Target middle-income to high-income earners
* Focus marketing on customers aged 30–45
* Promote bikes as a commuting solution for short distances
* Run region-specific campaigns
