# Bike Sales Analysis

## Overview
This project explores a bike sales dataset to identify patterns in customer purchasing behavior.

## Objectives
- Understand customer demographics
- Identify factors influencing bike purchases
- Generate insights for business decisions

## Tools Used
- Python
- Pandas
- Matplotlib 
- Jupyter Notebook

## Dataset
The dataset includes:

-ID                
-Marital Status    
-Gender            
-Income            
-Children           
-Education        
-Occupation        
-Home Owner        
-Cars              
-Commute Distance  
-Region            
-Age               
-Purchased Bike 

## Key Insights
- Customers with higher income were more likely to purchase bikes
- Age group 30–45 showed the highest purchase rate
- Commute distance influenced buying decisions
